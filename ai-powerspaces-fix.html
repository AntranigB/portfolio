The dock kept blocking part of my windows. I wanted the missing option to keep windows clear of it, so I had AI code a fix.

View the vibe-coded fix on GitHub ↗

What it does

I used AI to modify PowerSpaces with a dock-clearance option. The change calculates a usable window area around the custom dock and uses macOS Accessibility APIs to resize or reposition windows. The setting includes an adjustable gap and requires Accessibility permission.

How it was built

Vibe-coded project: I supplied the idea, requirements, and feedback; AI wrote the implementation.

Technology: Swift, AppKit, macOS Accessibility APIs, display geometry and window bounds.

Rough edges

It sometimes makes moving windows a pain! The fix automatically moves or resizes windows to keep them clear of the dock, so it can fight where I am trying to drag a window. Turning off “Keep windows clear of the dock” stops that behavior.

Public code

The fix is available on GitHub as a patch for PowerSpaces, with setup instructions, the new Swift files, and tests. It is an unofficial modification of Sebastian Panman de Wit’s PowerSpaces app.

Current status

Completed for the dock-clearance fix. The development chat records a live check of Chrome windows on two displays with the default 4-point gap. Other apps and display arrangements may behave differently.
